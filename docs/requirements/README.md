# VNA HAT requirements

Requirements for this project.

| ID | Requirement | Priority | Status |
|---|---|---|---|
| VNA-001 | This HAT is a complete project: hardware, case, firmware, software, OpenDAP OS package and its own tooling. | must | Confirmed |
| VNA-002 | Its OpenDAP OS software shall be a custom implementation built on popular open-source software for its domain, optimized for this HAT and the board. | must | Confirmed |
| VNA-003 | It shall mount through the HAT Case Standard. | must | Confirmed |
| VNA-004 | It may include on-board AI features. | should | Draft |
| VNA-005 | The HAT shall be a vector network analyzer based on NanoVNA. | must | Confirmed |
